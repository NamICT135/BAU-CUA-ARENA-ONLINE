## 28. Phases 6/7 — Implementation Record

### Files changed
- `index.html`: loading balance placeholders, initially disabled betting controls, dynamic chip status, disabled SHAKE and removal of static-preview note.
- `src/main.js`: API initialization and frontend betting behavior.
- `src/style.css`: selected chip checkmark/border, disabled states, hover restrictions and visible error status.
- Supplied `PROJECT_STATE.md`: updated completed phases, current behavior, tests and next phase.

`server.js`, `game-config.json`, `vite.config.js`, `package.json` and `package-lock.json` are unchanged, verified using SHA-256 comparisons. No dependencies were added.

### Functions introduced
- `loadInitialData`, `fetchJson`, `validateInitialData`
- `setBettingEnabled`, `showStatus`
- `selectChip`, `setSelectedChipUI`
- `placeBet`, `resetBets`, `getTotalBet`
- `renderBets`, `renderBalance`, `renderTotalBet`
- `attachEventListeners`

### Initialization and API calls
1. GET `/api/config`, check response.ok, parse JSON.
2. GET `/api/state`, check response.ok, parse JSON.
3. Validate configured symbol/chip mappings against the existing HTML and validate the returned state.
4. Copy state.balance to currentBalance; choose config.chips[0]; initialize each configured symbol property in the const bets object to zero.
5. Render the display, attach listeners and enable betting.

The config determines allowed symbols/chips. No authoritative current balance is hard-coded in JavaScript. Cached DOM references and textContent are used. A caught startup failure shows a live-region message and keeps controls disabled.

### Betting behavior
- Only one numeric chip is selected; class, checkmark and aria-pressed update together.
- Clicking a symbol adds the selected chip if it fits within currentBalance minus getTotalBet().
- Object.values(bets).reduce(...) calculates the current total.
- Rejected bets leave amounts unchanged and show the available balance.
- RESET BET sets all local amounts to zero; balance and chip selection are unchanged; no API call is made.
- SHAKE remains disabled with no listener, POST call or random dice generation.
