    HOW TO PLAY

    Six familiar symbols.
    Five simple steps.

    ✳
    1. Select a virtual coin chip.
    2. Choose one or more symbols.
    3. Press SHAKE.
    4. The Node.js server generates three symbols.
    5. Your return depends on how many times the selected symbols appear.

    Virtual coins are for educational demonstration only and have no monetary value.
